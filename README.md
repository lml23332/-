# 校门口小卖部（Codex 开发项目包）

一款《深空当铺》式当铺经营 × 中国校门口小卖部的单机小游戏：
**白天收货鉴定砍价，晚上盘账交租，攒够 ¥3000 把小卖部盘下来。**

本包是从已跑通的网页原型整理出的干净独立工程（零依赖、原生 HTML/CSS/JS），
供在 Codex 中继续迭代开发，并作为将来移植微信小游戏的玩法与数值蓝本。

## 玩法一句话

顾客上门卖货 → 你限次鉴定真假（只给线索不给答案）→ 砍价收购入货架 →
白天买家穿插上门点名购买 → 收摊自动售卖结算 → 每 7 天交租 →
口碑、戳戳乐、集贴纸、熟客赊账一起经营，攒够 ¥3000 盘下店面。

## 如何本地运行

任选其一：

1. **直接打开**：双击 `index.html` 用浏览器打开即可玩（file:// 协议可用）。
2. **静态服务器**（更接近线上环境）：
   ```bash
   cd xiaomaibu-codex-project
   python3 -m http.server 8000
   # 浏览器访问 http://localhost:8000
   ```
   或 `npx serve .` 等任意静态服务器。

无需构建、无需联网、无第三方依赖。

## 开发版变更

- 收摊后恢复结算画面，确认「明天开店」再推进日期。
- 买家到柜台时根据现有货架挑货并报价。
- 鉴定记录物品，收购后才解锁成色。
- 结算显示白天进货支出，并用开店和收摊余额计算今日净变化。
- 本版使用独立存档。原型存档缺少结算阶段，旧档继续在原型里使用。

## 存档说明

- 存档走浏览器 **localStorage**，键名 `xiaomaibu-save-v2`。
- 内容：天数、资金、口碑、货架、定价策略、戳戳乐板面、集贴纸状态、
  赊账本、图鉴、熟客好感度、当日访客队列与统计。
- 每次状态变化后自动保存；刷新/重开页面自动续玩。
- 游戏内「重新开店」按钮会清空存档重开（带二次确认）。
- 存档结构升级时记得改键名后缀（如 `-v2`）或写迁移，避免老存档报错。

## 后续开发路线

### 近期迭代建议（Codex 可直接接手）

1. **数值平衡**：先玩 3–5 局记录「到 ¥3000 的天数」，再只改 `js/data.js`
   里的 `CONFIG` 调节奏（目标：一局约 25–40 天达标）。
2. **内容扩充**：物品从 29 件扩到 60+（结构见 DESIGN.md「物品数据结构」，
   每件补 4 个检查点 × 3 套线索即可）；熟客专属剧情事件。
3. **表现升级**：按 `assets/style-sample.webp` 的真实画风批量出物品图，
   替换现在的 emoji 图标（图片放 `assets/items/`，在 data.js 里加 `img` 字段）。
4. **事件系统**：把投诉、赖账、良心小卖部等一次性事件抽成可配置事件池。
5. **音效与动效**：成交撒花、戳洞音效（WebAudio 合成即可，不引资源）。

### 移植微信小游戏（正式版路线）

- **引擎**：Cocos Creator 重写表现层；本包的 `data.js` 数值与 `game.js`
  规则可直接对照移植（数据与逻辑已分离，就是为了这一步）。
- **主体与变现**：个人主体、无版号、纯广告变现（IAA）。
  - 注册小游戏账号（类目选「游戏」）→ 微信认证（¥30）→ 开发者工具上传
    开发版 → 提交审核（网络类型选「单机」）→ 发布上线。
  - **小游戏备案与版本审核并行**：备案约 10 个工作日，审核中可同步提审、
    发布；单机游戏无需小程序备案那一步，不要被卡住。
  - 流量主：累计独立访客达 1000 后开通广告位（激励视频为主）。
- **广告点清单**（原型里已留占位/规则位，移植时接激励视频）：
  1. 鉴定提示：看广告得一次「八成真假」提示（原型中为免费占位按钮）。
  2. 额外顾客：收摊前看广告多接待 1 位卖家/买家。
  3. 房租减免：交租日看广告减免本次房租 30%。
  4. 戳戳乐免费进货：一块板看广告免进货费。
  5. 集贴纸安抚：嘀咕值高时看广告发一波试吃，嘀咕值清零。
  6. 离线/收摊收益翻倍：结算时看广告，本日自动售卖收入 ×1.5。
- **宣发提示**：开发日志本身就是获客渠道（同题材套圈游戏靠开发帖起量），
  上线同步发小红书/抖音开发故事帖。

## 已知取舍（原型 → 本包）

- 表现层做了简化：物品用 emoji + 色块呈现（真实画风图片待批量替换），
  无音效；但**全部玩法规则齐全**（买家、定价策略、戳戳乐、集贴纸、
  熟客、赊账、图鉴、结算分栏）。
- 顾客台词为自创模板句，不含任何现成 IP 的角色名与形象；
  戳戳乐图案为通用图案，不使用任何卡通 IP（包括阿狸）。
- 品牌相关物品做了模糊化处理（如「田宫四驱车」保留品类称呼，
  线索文案为自创；正式版上线前建议再做一轮商标排查）。

## 售货窗口试玩版

双击 index.html 开始。点击窗前顾客打开交易窗口，检查商品并出价。
收来的货默认摆上窗台。在「经营手册 → 货架」可以收回或重新摆出，
陈列状态只改变窗口展示。街上走动的人是场景动画，窗前的顾客可以接待。

场景素材为 assets/school-window.png，由内置 ImageGen 生成。
提示词概要：第一人称从怀旧校门口小卖部的红雨棚售货窗向外看，
保留木柜台和空人行道，午后暖光，清晰块状像素，无人物、文字或商标。

## 供货商进货

点击窗台「进货」打开供货商。干脆面、橘子汽水和田字格本按批采购，每种商品每天限订一批，现金付款、即时到货。
新货自动摆上窗台，可在营业时按件出售，也会参加收摊自动售卖。报价随定价策略和口碑变化，采购费纳入当天结算。
首次进货时，如果今天没有正在接待或排队的买家，会加排一位买家。

## 主菜单与新手引导

打开游戏先进入主菜单。首次开店默认有操作提示，老存档可用「继续营业」，
也可选「新手引导」随时开启提示。提示跟随验货、出价、供货和收摊进度，
第一天结束后自动关闭。营业中可以主动退出引导。

## 顾客立绘版交易窗口

宽屏左侧显示顾客想买或想卖的物品、价格和耐心，中间显示立绘，
底部显示角色名与当前对话，右侧保留验货和报价。窄屏把操作移到对话下方。
素材 assets/customer-portraits.png 由内置 ImageGen 生成。
提示词概要：透明背景横排四列，校门口小卖部的原创像素风半身顾客，
校服少年、卷发阿姨、戴帽老人、青衣年轻女性，无文字或商标。

## 主场景交易

顾客立绘站在售货窗前。点击立绘或接待牌，在原场景展开交易信息、对话与操作。
宽屏把商品与耐心叠在窗口左边，验货和出价叠在右边；窄屏把它们排在对话下方。
再次点击顾客可以收起操作，已经查看的线索仍会保留。处理完交易后下一位顾客到窗前。

## 场景对话与物品验货

点击窗前来卖货或买货的顾客，对话显示在场景窗沿内、人物身前。
新店首位顾客会带来掌上游戏机。可翻看正背面，点击屏幕、按键、电池仓和刻字标记。
首次检查部位消耗一次机会，复看已查线索不消耗次数。其他商品暂用文字验货。
assets/handheld-inspection.png 由内置 ImageGen 生成。提示词概要：同一台原创无商标
像素掌机的正背面并排，正面展示屏幕和按钮，背面展示电池盖和刻印。

## 窗沿与账本

流水账从窗台的「流水账」按钮打开，可以用「合上账本」返回经营。
出价或进货资金不足、无效出价和未接待完时尝试收摊，会在界面上方显示提示并写入流水账。

## 全物品图与交互

29 件旧货、3 件供货商商品及金龙贴纸均有像素绘图。旧货点图上的编号验货，
掌机可翻正背面。零售商品在供货商、窗台、货架、买家面板和结算清单可点图查看，
打开详情后再次点图片放大。旧存档的历史成交记录会按原样显示。
素材 assets/items-a.png 和 assets/items-b.png 由内置 ImageGen 生成。
提示词概要：怀旧校门口小卖部原创像素物品，两张四行四列等分图集，
深绿底，每格一件，按 js/data.js 中 ITEM_ATLASES 的顺序排列，无文字或商标。
除掌机外，旧货当前使用单张物品图和四个检查点，内部与背面部位用对应标记查看线索。

## 街坊经营版

新版本的可编辑玩法说明随包提供，见 GAME-PROMPT.md。
用窗台货架缩略图打开木货架；验货、选商品和报价通过按钮切换。
第一天林姨说明目标，后续按第 2、3、5、7 天加入街坊服务及房东提醒。
浏览器内点击「音乐」可切换循环旋律。旧存档会以原口碑 50 为零点迁移，现有食品从迁移当天开始计时。
NPC 四列图集由内置 ImageGen 生成，依次为邻里导师、社区宣传员、房东与配送员。
